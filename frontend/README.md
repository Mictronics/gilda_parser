# GILDA viewer Frontend

## Used components

- [Vue.js](https://vuejs.org) Progressive JavaScript Framework
- [Primevue](https://primevue.org) Next-Gen UI Suite for Vue.js
- [Primeflex](https://primeflex.org/) Primevue CSS Utility Companion

## Project setup

```bash
npm install
```

### Compiles and hot-reloads for development

```bash
npm run serve
```

Expects Python backend running on [http://127.0.0.1:5000](http://127.0.0.1:5000). Start with `Viewer` debugger in VSC. See also vue.config.js.

### Compiles and minifies for production

```bash
npm run build
```

### Lints and fixes files

```bash
npm run lint
```
